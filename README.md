# LLM Fundamentals

A beginner-to-intermediate exploration of Large Language Models using Python and Groq API.

## What's inside
- `main.py` — Terminal chat app connected to Llama 3 via Groq API

## Tech Stack
- Python
- Groq API (Llama 3.3 70B)
- python-dotenv

## How to run
1. Clone the repo
2. Create a `.env` file and add your `GROQ_API_KEY`
3. Install dependencies: `pip install groq python-dotenv`
4. Run: `python main.py`

## What I learned
- How to connect to an LLM via API
- How to structure system prompts and user messages
- How to secure API keys using environment variables
